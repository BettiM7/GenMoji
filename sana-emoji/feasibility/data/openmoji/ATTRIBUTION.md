# OpenMoji feasibility subset

Emojis designed by [OpenMoji](https://openmoji.org/), the open-source emoji and icon project by HfG Schwäbisch Gmünd and contributors.

Source release: 17.0.0. License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). See LICENSE.txt and manifest.json for per-file sources and hashes.

Captions are project-authored. No evaluation prompts or generated baseline images are used. Only the first pair is used for the single optimizer update; all eight images are loaded and validated.
